    Encrypt & Decrypt
    

    Core encryption
    AES-256-GCM encrypts the document locally. A fresh random 256-bit CEK and 12-byte IV are used per encryption.
    

    Password protection
    PBKDF2-SHA-256 + random 16-byte salt + 300,000 iterations derives the key used to wrap the CEK.
    

    Persistent recovery
    A separate random 256-bit Recovery Key wraps the same CEK and can be reused for decrypt or password reset.
    

    Encrypted file
    EF-SECRET/1 stores ciphertext plus required cryptographic metadata. The plaintext and password are not stored in readable form.
    

    Browser runtime
    Encryption and decryption run locally through the browser's Web Crypto API; no server is required for the cryptographic operation.
    

    Recovery rule
    Losing both the password and Recovery Key means this app cannot recover the encrypted plaintext.
